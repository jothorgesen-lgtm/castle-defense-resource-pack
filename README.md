# Castle Defense resource pack

The resource pack for **Castle Defense**, a co-op castle wave-defense minigame for Minecraft Java 26.3. It adds the huge red Blood Moon, the gray stone boss statues in the Great Hall, and the Vanilla Tweaks the game uses.

## Download

**[Download the current pack](https://github.com/jothorgesen-lgtm/castle-defense-resource-pack/raw/main/Castle-Defense-Resource-Pack.zip)**

That link always gives the newest version. No GitHub account needed. There's also a [download page](https://jothorgesen-lgtm.github.io/castle-defense-resource-pack/) with the same link and the install steps.

Current version: **KXAMW**, updated Nov 19, 2026.

## Install

1. Download the zip. Don't unzip it.
2. In Minecraft, open **Options → Resource Packs → Open Pack Folder**, and drop the zip in.
3. Back in the Resource Packs screen, move **Castle Defense** to the right-hand side and click **Done**.

When the pack gets a new version, download it again and replace the old zip.

Without the pack the game still works: the moon stays white and the statues show as plain stone.
